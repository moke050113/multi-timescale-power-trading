## 📋 项目概述

本项目研究面向含电动汽车和工业可转移负荷的用户侧聚合主体，在中长期—现货多时间尺度市场环境下的购电与柔性负荷协同决策问题。采用**分层架构**（上层SAC智能体 + 下层规则调度器）实现交易仓位与可调负荷的动态优化。

### 核心贡献

1. **多时间尺度交易框架**：年度/月度/月内/现货四级市场，仓位约束衔接（α≤β≤γ）
2. **分层架构设计**：上层SAC智能体决策仓位比例，下层规则调度器管理柔性负荷
3. **序贯决策优化**：单智能体通过序贯动作自然处理多时间尺度，避免信用分配问题
4. **完整实验验证**：5种价格场景 × 1000 episodes，平均改进 **+24.0%** vs 固定比例

## 🎯 研究问题

**任务书要求**：
> 面向含电动汽车和工业可转移负荷的用户侧聚合主体，研究中长期—现货多时间尺度市场环境下的购电与柔性负荷协同决策，并针对不同交易时间尺度构建相互衔接的深度强化学习智能体，实现交易仓位与可调负荷的动态优化。

**我们的解决方案**：
- ✅ 多时间尺度市场：年度/月度/月内/现货四级市场
- ✅ 柔性负荷模型：电动汽车集群 + 工业可转移负荷
- ✅ 分层架构：上层SAC（DRL）+ 下层规则调度器
- ✅ 序贯决策：单智能体在4个时间尺度依次决策

## 🏗️ 系统架构

```
┌─────────────────────────────────────────────┐
│  上层 SAC 智能体 (DRL)                       │
│  - 动作空间: 1维 (ratio_raw)                 │
│  - 决策: α/β/γ 仓位比例                      │
│  - 触发: 年度/月度/月内阶段 (25次/episode)    │
└──────────────────┬──────────────────────────┘
                   │ 仓位约束 (α ≤ β ≤ γ)
┌──────────────────▼──────────────────────────┐
│  下层规则调度器 (FlexibleDispatcher)          │
│  - 策略: 高价减载/放电, 低价增载/充电         │
│  - 触发: 现货阶段 (12次/episode)              │
│  - 对象: EV集群 + 工业负荷                    │
└─────────────────────────────────────────────┘
```

### 为什么采用分层架构？

**多智能体方案失败原因**：
- 成本不对称：中长期合同占95%，现货仅5%
- 信用分配问题：现货智能体动作对总成本影响<0.2%，无法从全局奖励中学习
- 参考项目实证：PPO下层不如规则基线（年节省1082万元）

**分层架构优势**：
- 避免信用分配问题（单DRL智能体）
- 各用所长：DRL处理复杂决策，规则处理凸优化
- 训练稳定：+24%改进，收敛良好

### 主要结果：分层架构 vs 基线

### 关键发现

1. **分层架构显著优于基线**：平均节省24%成本（约28万元/年）
2. **场景E改进最大**（+33.6%）：现货极端风险下，SAC学会提高中长期覆盖率
3. **规则调度器稳定工作**：柔性节约900-2100元/月，转移惩罚仅37-40元
4. **学到序贯策略**：发现"收官效应"（年末γ骤降至0.45-0.58）

## 🔬 核心算法

### SAC (Soft Actor-Critic)

- **Actor网络**：高斯策略，输出动作均值和标准差
- **Critic网络**：Twin Q-networks，减少过估计
- **自动熵调节**：平衡探索与利用
- **经验回放**：打破样本相关性

### 多时间尺度决策

```python
# 每个episode执行37步
Step 1:    年度阶段 → 决策 α（影响全年12个月）
Step 2-13:  月度阶段 → 决策 β_1, ..., β_12（每月一次）
Step 14-25: 月内阶段 → 决策 γ_1, ..., γ_12（每月一次）
Step 26-37: 现货阶段 → 规则调度器自动执行
```

**仓位约束**：`0 ≤ α ≤ β ≤ γ ≤ 1`

### 规则调度器

```python
# 基于现货价格百分位的削峰填谷
高价时段 (top 25%):
  - EV 放电 50% 容量
  - 工业减载 50% 可减空间
  
低价时段 (bottom 25%):
  - EV 充电 50% 容量
  - 工业增载（能量守恒）
```
