## 📋 项目概述

本项目研究面向含电动汽车和工业可转移负荷的用户侧聚合主体，在中长期—现货多时间尺度市场环境下的购电与柔性负荷协同决策问题。采用**双 DRL 智能体**（中长期 SAC + 柔性调度 SAC）实现交易仓位与可调负荷的动态优化，并另设分层臂（上层 SAC + 规则下层）与两个规则臂作对照。

### 核心贡献

1. **多时间尺度交易框架**：年度/月度/月内/现货四级市场，按交割月记账（`R_m`、合同台账、偏差结算）
2. **双 DRL 智能体**：中长期 SAC 决策 α/β_m/γ_m（25 个决策），柔性调度 SAC 决策调度强度（12 个决策），
   按各自决策时序衔接（半 MDP，跨步折扣 γ^Δt）
3. **可验证的经济与物理闭环**：设备动作真正改变网侧电量，缺口/富余按显式规则结算，
   58 个验收用例覆盖"无虚假退款、电量守恒、设备按时完成、费用可手算、观察不含未来实现值、模型重载一致"
4. **四臂配对世界基准**：固定比例＋保障调度 / 滚动规则＋预测调度 / 上层 SAC＋规则下层 / 双 SAC，
   同世界、同设备任务、冻结预算与种子，逐回合复核后才进入汇总

## 🎯 研究问题

**任务书要求**：
> 面向含电动汽车和工业可转移负荷的用户侧聚合主体，研究中长期—现货多时间尺度市场环境下的购电与柔性负荷协同决策，并针对不同交易时间尺度构建相互衔接的深度强化学习智能体，实现交易仓位与可调负荷的动态优化。

**我们的解决方案**：
- ✅ 多时间尺度市场：年度/月度/月内/现货四级市场，逐交割月合同台账
- ✅ 柔性负荷模型：电动汽车集群（SOC 时序积分 + 效率）+ 工业可转移负荷（日任务守恒）
- ✅ 相互衔接的双 DRL 智能体：中长期 SAC + 柔性调度 SAC（独立经验池、按角色决策时序）
- ✅ 序贯决策：每个 episode 37 步（1 年度 + 12×(月度 + 月内 + 现货)）

## 🏗️ 系统架构

```
┌─────────────────────────────────────────────┐
│  中长期 SAC 智能体                            │
│  - 动作空间: 1维 (ratio_raw)                 │
│  - 决策: α / β_m / γ_m 覆盖率                │
│  - 触发: 年度/月度/月内阶段 (25次/episode)    │
└──────────────────┬──────────────────────────┘
                   │ 本月合同覆盖率 γ_m → 现货暴露 1-γ_m
┌──────────────────▼──────────────────────────┐
│  柔性调度 SAC 智能体                          │
│  - 动作空间: 1维 (强度 ∈ [-1,1])             │
│  - 只决定"多大程度择优调度", 采购量由缺口决定 │
│  - 触发: 现货阶段 (12次/episode)              │
└──────────────────┬──────────────────────────┘
                   │ 强度 → 设备执行层
┌──────────────────▼──────────────────────────┐
│  设备执行层 FlexibleExecutor                  │
│  EV SOC 积分(η_in/η_out) + 工业任务守恒        │
│  → 真实网侧电量 → 偏差结算(缺口买入/富余回售) │
└─────────────────────────────────────────────┘
```

### 为什么需要信用分配机制？

- 成本不对称：中长期合同主导成本（新口径实测占 92%~99%、均值 94.7%，`experiments/measure_reward_scale.py`），柔性调度只影响剩余偏差
- 直接共享全局奖励时现货侧信号信噪比过低，学不到梯度；按各自电量基准归一后实测 $|r_{\text{spot}}|/|r_{\text{mid}}|$ = 1.5~10.2（均值 6.9）
- 对策：**分阶段奖励 + 按各自电量基准归一**，并在月内步加入"未来暴露成本塑形"（只用公开滚动预测）
- 对照：分层臂（上层 SAC + 规则下层）作为基线保留，用于检验"第二个智能体是否真的带来增益"

### 已达成（可复算）

| 验收项 | 状态 |
|--------|------|
| 逐月交割合同台账（`γ_m·R_m`，Σ R_m = Q） | ✅ 台账总量 = 全年实际网侧净需求，残差 < 1e-6 |
| 现货偏差结算（缺口按小时现货 1:1 买入，过购按现货 ×0.8 回售） | ✅ 无负量合同、无虚假退款 |

### 四臂配对世界基准（正式结果，5 场景 × 4 臂 × 3 种子 × 2000 回合）

评估阶段每个 (场景, 臂, 种子) 在 10 个**同一世界**上确定性重放；600 个世界的会计/物理验收
失败数为 0。判读门槛：改进需明显大于 0.4%（同种子跨进程实测噪声 0.09%~0.37%）
且 3 个种子 × 10 个世界方向一致。单位元/年。

| 场景 | 固定比例＋保障调度 | 滚动规则＋预测调度 | 上层 SAC＋规则下层 | 双 SAC |
|------|-------------------|--------------------|--------------------|--------|
| A 年度低价后期上涨 | 314,643 | 314,214 (+0.14%) | 309,116 (+1.62%) | **308,397 (+1.85%)** |
| B 年度高价后期下降 | 403,243 | **399,166** | 407,536 (−2.10%) | 404,776 (−1.41%) |
| C 各阶段价格接近 | 351,437 | 351,705 (−0.08%) | 351,074 (+0.18%) | 349,181 (+0.72%) |
| D 现货高波动 | 344,677 | 344,145 (+0.15%) | 342,888 (+0.37%) | **341,471 (+0.78%)** |
| E 月度低价现货极端风险 | 377,163 | **368,854** | 377,480 (−2.34%) | 377,620 (−2.38%) |

括号内为**相对滚动规则强基线**的配对改进（相对固定比例基线的数值见 `report/课程设计报告.md` 表 5.4-1）。

**结论（负面，但机制可定位）**：5 场景均值 `rolling_rule` 相对弱基线 +0.69%，
`dual_sac` +0.61% 但相对滚动规则 **−0.09%**，`sac_rule` +0.25% / **−0.45%**。
因此**"双 DRL 优于规则策略"在本文预算与信息设定下不成立**。
原因是两条学习臂的年度覆盖率在所有场景都饱和在动作上限 $\alpha\approx0.89$（规则为 0.80），
而年度决策时点观察里月度/月内价尚未公布；于是学习臂改进的符号**完全**由
"年度层均价是否低于月度层"决定（A/C/D 为正、B/E 为负，5/5 一致）。
柔性调度臂在现货层有一致的正向描述（现货成交均价 5 场景均低于规则臂），
但因各臂现货电量口径不同，只作描述性结果；单独剥离第二个智能体
（`dual_sac` vs `sac_rule`，同种子同世界配对）的增量是 5 场景均值 **+0.37%**
（B/C/D 30/30 世界全胜，A/E 不成立），方向可信但幅度未达 0.4% 门槛。
全部表格与图由 `results/four_arm_benchmark.json` 经 `report_tables.py` /
`plot_four_arm_results.py` 生成，无人工填数。

### 消融（场景 A，同种子同世界配对，报告 5.9 节）

三个设计部件各跑一个剔除变体（`experiments/run_ablation.sh`，冻结预算与主基准逐字段一致，
150 个评估世界验收失败 0 条）。**正号 = 关掉该部件后更贵 = 该部件在完整方法里有正贡献**：

| 剔除部件 | `sac_rule` | `dual_sac` | 判读 |
|----------|------------|------------|------|
| 未来暴露成本塑形 | **+1.70%** (30/30) | **+1.40%** (30/30) | 唯一超过 0.4% 门槛，3/3 种子同号 |
| 现货奖励放大 | +0.26% (24/30) | +0.07% (20/30) | 门槛之下，逐种子符号不一致 |
| 三阶段交替训练 | — | +0.05% (22/30) | 门槛之下，逐种子符号不一致 |

关闭塑形后月内覆盖率均值从 0.973/0.967 掉到 0.875/0.848：三个部件里只有它在承重。
该结论**仅限场景 A 与两条学习臂**，不足以支持"另两个部件可以删除"（旧版那样写过，已作废）。
逐格数值由 `experiments/verify_report_numbers.py` 从 `results/parts/ablation_*.json` 当场重算核对。

## 🔬 核心算法

### SAC 双智能体（按角色分工）

- **上层 中长期仓位 SAC**（角色 `midlong`，每回合 25 次决策：年度 α 1 次 + 月度 β_m 12 次 + 月内 γ_m 12 次）
- **下层 柔性调度 SAC**（角色 `spot`，每回合 12 次决策，每月现货阶段 1 次）
- 共享 SAC 实现：高斯 Actor、Twin Critic、自动熵调节、带 `γ^Δt` 折扣的经验回放

### 决策与约束

```text
每回合 37 步 = 年度 1 + (月度 1 + 月内 1 + 现货 1) × 12
年度:  签 1 次全年合同   α          (覆盖基准 R_m 上的全年统一覆盖率)
月度:  每月滚动加签      β_m        (同月层内 α ≤ β_m)
月内:  每月再滚动加签    γ_m        (同月层内 β_m ≤ γ_m)
现货:  只决定柔性强度    u_m ∈ [-1, 1]
合同电量 = γ_m · R_m,  Σ_m R_m = Q
现货偏差 = A_m − γ_m · R_m  (A_m 为设备执行后的真实网侧净需求)
```

- 同月层内 α ≤ β_m ≤ γ_m 由断言强制；跨月允许降低覆盖率，但**不退款、不冲销已签合同**。
- 柔性强度正号=增载/充电，负号=减载/放电；该智能体**不决定现货采购电量**，
  现货侧只有合同与实际需求之间的偏差，由结算引擎计价（缺口 1:1 买入，过购 ×0.8 回售）。

### 物理执行器 `FlexibleExecutor`

执行顺序严格为：**合法观察 → 智能体动作 → 设备实际执行 → 真实网侧电量 → 市场结算**。

- EV 集群：η_in 0.90 / η_out 0.88，按小时积分 SOC；到达/离开比例约束可用车辆；
  离场前目标 SOC 必达；放电上限用闭式可行解；同一小时不同时充不放；小时净负荷不为负。
- 工业可转移负荷：刚性部分不可动，可转移部分保持**日任务电量守恒**，
  超窗不可行的调整采用 commit-or-rollback 直接回退。
- `demand_scale` 只在中性（强度恒为 0）剖面上标定一次，动作之后**不再重新归一化**。

### 训练时序（半 MDP）

每个 SAC 的 `next_state` 是**本角色自己的下一次决策观察**，TD 折扣取 `γ^Δt`（Δt 入回放）；
回合末尾未闭合的挂起决策按终止写入、不再 bootstrap。
阶段：P1 只训练中长期（25%）→ P2 冻结中长期、训练柔性（25%）→ P3 联合（50%）。
重载时用 `log_alpha.copy_()` 原地写入，保证温度优化器参数绑定不失效；
检查点带维度/形状指纹，`action_scale`、`target_entropy`、`gamma`、`tau` 不一致直接报错。

### 规则臂（可复算基线）

`src/agent/rule_policies.py` 提供两支不学习的对照策略：
`fixed_ratio_action`（固定比例 α/β/γ = 0.80/0.90/0.95 + 保障调度，即任务书意义上的保守基线）
与 `rolling_rule_action`（逐层滚动比价 + 按公开日前剖面的价差强度调度）。
强度只在净价差（日内波幅 − 工业转移惩罚）超过物理门槛（往返损耗 + 过购折卖折价 ≈ 0.46）
时启用放电，且放电量受"本月剩余偏差空间"限制。
